# Ответы на вопросы по Практической работе №5: CSS Grid Layout

1. **Какое основное свойство включает CSS Grid и чем принципиально отличается от Flexbox?**
   CSS Grid включается свойством `display: grid`. Основное отличие от Flexbox заключается в размерности: Flexbox является одномерной системой (компонует элементы строго в один ряд ИЛИ одну колонку), а CSS Grid — это двумерная система. Она позволяет одновременно управлять и строками, и колонками, создавая сложные пересекающиеся сетки макетов.

2. **В чем разница между grid-template-columns и grid-auto-columns?**
   - `grid-template-columns` определяет явную сетку, то есть жестко задает размеры и количество конкретных колонок, которые разработчик спроектировал заранее.
   - `grid-auto-columns` управляет размерами колонок неявной сетки, которые создаются браузером автоматически, если контент "вываливается" за рамки изначально описанного шаблона.

3. **Что делают функции repeat(), minmax() и auto-fit в определении grid-шаблона?**
   - `repeat(кол-во, размер)` — избавляет от дублирования кода, заставляя браузер повторить нужный размер колонок указанное число раз. Например, `repeat(3, 1fr)`.
   - `minmax(min, max)` — задает динамический диапазон размеров. Элемент не сожмется меньше значения `min` и не растянется больше значения `max`.
   - `auto-fit` — автоматически рассчитывает количество колонок в ряду, забивая доступное пространство. Если места много, пустые колонки схлопываются, растягивая существующие элементы на всю ширину.

4. **Как работают именованные grid-областей и какие преимущества они дают?**
   Через свойство `grid-template-areas` описывается текстовый визуальный шаблон сетки (например, `"header header" "nav main"`). Затем дочерним элементам через `grid-area` присваиваются эти имена. Преимущество — невероятно наглядный код и легкая адаптивность: в медиа-запросе достаточно просто переписать текстовую карту шаблона.

5. **Объясните систему нумерации grid-линий и размещение через grid-column и grid-row.**
   Браузер нумерует линии сетки (границы колонок и строк) натуральными числами начиная с 1. Свойство `grid-column: 1 / 3` указывает элементу занять пространство от 1-й вертикальной линии до 3-й линии (то есть растянуться на 2 колонки). Аналогично работает `grid-row` для строк. Ключевое слово `span` указывает, на сколько ячеек нужно растянуть элемент от текущей позиции.

6. **Что такое gap и чем он лучше margins?**
   Свойство `gap` задает расстояние между ячейками сетки (строками и столбцами). Оно лучше `margin`, потому что применяется исключительно внутри сетки между элементами. Оно не создает лишних отступов по краям родительского контейнера, предотвращая поломку макета и избавляя от необходимости писать костыли вида `:last-child { margin-right: 0; }`.

7. **Как свойства justify-items и align-items влияют на выравнивание grid-элементов?**
   - `justify-items` выравнивает содержимое всех grid-элементов по горизонтали (вдоль оси строк) внутри их ячеек (значения: `start`, `end`, `center`, `stretch`).
   - `align-items` выравнивает содержимое элементов по вертикали (вдоль оси колонок) внутри их ячеек.

8. **В чем разница между auto-fill и auto-fit при создании адаптивных сеток?**
   - `auto-fill` создает максимально возможное количество колонок в ряду, даже если они останутся абсолютно пустыми (браузер резервирует под них пустое место).
   - `auto-fit` также создает колонки, но если они оказываются пустыми, они полностью схлопываются до 0px, а оставшиеся заполненные колонки расширяются и забирают себе всё свободное пространство ряда.

9. **Как создать сложные макеты с помощью grid-template-areas и какие правила существуют?**
   Макет описывается строками в кавычках, где каждая строка — это новый ряд сетки, а слова внутри — ячейки колонок. Правила: сетка должна быть прямоугольной; каждая область должна образовывать непрерывный квадрат или прямоугольник (L-образные области запрещены); если ячейку нужно оставить пустой, вместо имени ставится точка `.`.

10. **Какие преимущества дает CSS Grid перед другими методами верстки?**
    CSS Grid позволяет создавать полноценную двухмерную разметку без использования бесконечных вложенных тегов `<div>`. Он дает возможность полностью менять визуальное расположение блоков (например, менять местами сайдбар и контент) для мобильных устройств всего одной строчкой CSS, абсолютно не трогая саму структуру HTML-документа.
