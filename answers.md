# Ответы на вопросы для ПР №3

1. Разница в том, что класс (.important) можно использовать много раз на странице для разных элементов, а ID (#site-title) уникален и применяется только к одному элементу. У ID специфичность намного выше, чем у класса.

2. Каскад — это правила, по которым браузер решает, какой стиль применить, если они спорят между собой. Приоритет такой: сначала проверяется наличие !important, потом специфичность селектора, а если всё одинаково — побеждает то правило, которое написано в коде ниже.

3. Расчет специфичности:
- ul li.important -> 0,1,2 (1 класс, 2 тега)
- #site-title -> 1,0,0 (1 ID)
- .content > .featured-post -> 0,2,0 (2 класса)

4. Наследуются свойства текста: color, font-family, line-height. Не наследуются свойства блоков: border, padding, margin.

5. Селектор > выбирает только прямых детей (на один уровень ниже). Селектор через пробел выбирает всех потомков на любой глубине вложенности.

6. :hover срабатывает при наведении мыши (нужен для кнопок и ссылок). :nth-child() выбирает элементы по номеру (нужен для покраски строк таблицы через одну).

7. !important намертво закрепляет стиль, ломая каскад. Использовать нужно осторожно, так как его потом тяжело переопределить в коде.

8. Они создают виртуальные элементы до (::before) или после (::after) контента. Содержат свойство content (туда можно закинуть иконки, текст или декоративные стрелочки).

9. Браузер выберет то правило, которое написано в файле стилей ниже (последнее по счету).

10. Они позволяют прямо на сайте смотреть, какие стили применились, какие зачеркнулись из-за каскада, и временно менять их для тестов.
